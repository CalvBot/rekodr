Apps and audio tracks

Every clip has these audio tracks: 1 Mix (everything) · 2 Mic · 3 Communication (all chat apps together) · then one track per app, games first. Ignored apps are never recorded. The game list is shared with lifelog.
Games can have their own bitrate, used while it's the game being played (blank = the normal one). Switching costs about a second of footage.
Apps heard for the first time are marked New and listed first: pick a category for each. Right-click an app to open its file location.

Hotkeys

Keys like Alt+F10 (the default, same as NVIDIA), Ctrl+Alt+F9 or F13–F24. For a Stream Deck, the README’s clipbackw save 90s commands are simpler than hotkeys. Actions: save 30s, save 2m, save 1h (any length), open, pause.
